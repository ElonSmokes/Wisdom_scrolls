# Certificates, badges, and the achievement wall

Conditions checked: **24.09.2026**. Learning order: [WORK_INTEGRATED_ROADMAP.md](WORK_INTEGRATED_ROADMAP.md); actual progress: [PROGRESS.md](PROGRESS.md).

A certificate for a completed course is an achievement in its own right. You can print it as soon as it is issued. Applying the learning to a work project is recorded separately; it does not undo an award already earned.

<a id="какие-награды-здесь-есть"></a>

## Awards included here

| Award | Earned by | What to save |
|---|---|---|
| NVIDIA DLI course certificate | The specific course’s final assessment: CUDA Python and Building RAG Agents in the main queue | The issued certificate from your account, date, and verification link/ID if available |
| GitLab Certified CI/CD Associate | Passing a separate exam | Digital certificate with a verification code and a Credly badge |
| Linux Foundation LFS162 badge | Final exam ≥70% | The issued badge and public link if you want it public; a certificate PDF is not promised |
| CS50 Certificate | ≥70% on every problem and the final project of the corresponding course | The free CS50 certificate; purchasing verified edX is not required for this award |
| Full Stack Open certificate | Enough accepted exercises | Download from My submissions; university credits have separate conditions |
| HF Certificate of Fundamentals | Agents Unit 1 + quiz ≥80% | The issued certificate file/page from the current quiz app |
| Personal achievement | Your completed experiment, fix, or work improvement | A sheet with the date, result, and evidence; label it “Personal achievement” |

Use the actual names for course awards, badges, and professional certifications. Reading documentation or running your own benchmark does not promise a provider certificate.

<a id="сохранить-и-распечатать"></a>

## Save and print

1. When registering, enter your name as you want it to appear on the wall. After successful completion, check the name, course title, and date.
2. **NVIDIA:** the [official FAQ](https://www.nvidia.com/en-us/learn/training/support/) says earned certificates are in MyLearning. Open the issued certificate and save the available file; if it is a web page, use browser printing to PDF.
3. **GitLab / Linux Foundation:** accept the issued badge in Credly. [Image download instructions](https://support.credly.com/hc/en-us/articles/360020965172-Can-I-download-my-badge-image). A [certificate PDF](https://support.credly.com/hc/en-us/articles/360026639872-Can-I-download-and-print-my-badge-certificate) is available only if the issuer enables it; Credly requires the badge and profile to be public for this operation. Do not automatically change privacy settings just to print. If there is no PDF, use the issued badge image on your own sheet with its title and date.
4. **CS50 / Full Stack Open / HF:** open the earned certificate from the gradebook/submission/quiz system and save the offered file. If only a web version is available: Print → Save as PDF.
5. For paper: A4, orientation matching the layout, Fit to page, and browser headers/footers disabled. Save the original file separately from the print version.
6. Add the date, exact award name, verification URL/ID, and saved filename to the log. Example filename: `2026-10-15_nvidia_cuda-python_certificate.pdf` — this is only an example, not a record of issuance.

Post-issuance download steps within personal accounts were not performed: no one completed an assessment or issued a certificate on your behalf. Saving an award immediately reduces dependence on the course remaining available.

## Personal achievements for work results

[Separate template to fill in and print](templates/achievement.md). Complete it after the work: title, date, result, understanding, and evidence. No provider logos or qualifications you have not earned.

A neutral description is sufficient in a public log. Keep client data, internal links, and work infrastructure details in an approved corporate location. The earned course certificate and personal achievement for applying it have separate entries in [PROGRESS](PROGRESS.md).

<a id="перед-каждым-новым-курсом-2-минуты"></a>

## Before each new course: 2 minutes

The [course check form](templates/course-check.md) helps retain the date and observed conditions.

- There is a working enrollment entry point and no retirement/expiry that conflicts with your pace.
- The access period is clear. DLI: up to 6 months under the general policy, with separate lab limits; LFS162: 90 days; GitLab exam: 14 days after registration.
- The exact award you want and its requirements are specified.
- Purchase/registration is available for your account and country.

If a condition changes, mark the course “needs rechecking,” not “still recommended.” HTTP 200 or an old catalog does not confirm course availability.
