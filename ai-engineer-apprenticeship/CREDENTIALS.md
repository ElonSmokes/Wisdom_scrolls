# Сертификаты, badges и стена достижений

Проверка условий: **24.09.2026**. Порядок обучения — [WORK_INTEGRATED_ROADMAP.md](WORK_INTEGRATED_ROADMAP.md); запись фактического прогресса — [PROGRESS.md](PROGRESS.md).

Сертификат за законченный курс — самостоятельное достижение. Можно распечатать его сразу после выдачи. Применение в рабочем проекте отмечаем отдельно; оно не отменяет уже заработанную награду.

## Какие награды здесь есть

| Награда | За что | Что сохранять |
|---|---|---|
| NVIDIA DLI course certificate | Итоговая оценка конкретного курса: в основной очереди CUDA Python и Building RAG Agents | Выданный сертификат из кабинета, дату и ссылку/ID проверки, если есть |
| GitLab Certified CI/CD Associate | Сданный отдельный экзамен | Цифровой сертификат с verification code и Credly badge |
| Linux Foundation LFS162 badge | Финальный экзамен ≥70% | Выданный badge и публичную ссылку, если хочешь сделать её публичной; PDF сертификата не обещан |
| CS50 Certificate | ≥70% на каждой задаче и final project соответствующего курса | Бесплатный сертификат CS50; покупка verified edX для этой награды не требуется |
| Full Stack Open certificate | Достаточное число принятых упражнений | Скачать из My submissions; университетские кредиты имеют отдельные условия |
| HF Certificate of Fundamentals | Unit 1 Agents + quiz ≥80% | Выданный файл/страницу сертификата из актуального quiz-приложения |
| Личная ачивка | Твой законченный эксперимент, исправление или рабочее улучшение | Лист с датой, результатом и доказательством; подписывать «Личное достижение» |

Награды курса, badge и профессиональная сертификация обозначаются своими настоящими названиями. За прочитанную документацию или собственный benchmark провайдерский сертификат не обещаем.

## Сохранить и распечатать

1. При регистрации указать имя так, как оно должно выглядеть на стене. После успешного завершения проверить имя, название курса и дату.
2. **NVIDIA:** [официальный FAQ](https://www.nvidia.com/en-us/learn/training/support/) указывает, что earned certificates находятся в MyLearning. Открыть выданный сертификат и сохранить доступный файл; если выдаётся web-страница, использовать печать браузера в PDF.
3. **GitLab / Linux Foundation:** принять выданный badge в Credly. [Инструкция скачивания изображения](https://support.credly.com/hc/en-us/articles/360020965172-Can-I-download-my-badge-image). [PDF сертификата](https://support.credly.com/hc/en-us/articles/360026639872-Can-I-download-and-print-my-badge-certificate) доступен только если издатель включил эту функцию; для этой операции Credly требует публичные badge и профиль. Не менять приватность ради печати автоматически. Если PDF нет, использовать выданное изображение badge на своём листе с названием и датой.
4. **CS50 / Full Stack Open / HF:** открыть полученный сертификат из gradebook/submission/quiz-системы и сохранить предлагаемый файл. При доступной только web-версии — Print → Save as PDF.
5. Для бумаги: A4, ориентация по макету, масштаб Fit to page, выключить служебные headers/footers браузера. Сохранить исходный файл отдельно от версии для печати.
6. В журнал добавить дату, точное название награды, verification URL/ID и имя сохранённого файла. Пример имени: `2026-10-15_nvidia_cuda-python_certificate.pdf` — это только образец, не запись о получении.

Шаги скачивания из личных кабинетов после выдачи не исполнялись: никто не проходил assessment и не выпускал сертификат от твоего имени. Сохранение сразу после получения уменьшит зависимость от дальнейшего закрытия курса.

## Личная ачивка для рабочих результатов

Печатать после выполнения. Подойдёт обычный лист, без логотипов провайдера:

```text
ЛИЧНОЕ ДОСТИЖЕНИЕ

Название: [например, «Объяснил и измерил KV cache»]
Завершено: [дата]

Я сделал: [один конкретный результат]
Теперь понимаю: [механизм своими словами]
Проверено: [замер / тест / воспроизводимый пример]
Доказательство: [ссылка или ID приватной заметки]

Следующий шаг: [одно действие]
```

В публичном журнале достаточно нейтрального описания. Данные клиентов, внутренние ссылки и детали рабочей инфраструктуры хранить в разрешённом корпоративном месте.

## Перед каждым новым курсом: 2 минуты

- Есть действующий вход в запись, отсутствует retirement/expiry, мешающий твоему темпу.
- Понятно, сколько живёт доступ. DLI: до 6 месяцев по общей политике, labs ограничены отдельно; LFS162: 90 дней; GitLab exam: 14 дней после регистрации.
- Указаны именно нужная награда и условия её получения.
- Покупка/регистрация доступна для твоего аккаунта и страны.

Если условие изменилось, курс получает статус «нужна перепроверка», а не «всё ещё рекомендован». Статус HTTP 200 или старый каталог не подтверждает доступность курса.
