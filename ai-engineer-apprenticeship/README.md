# AI Engineer Apprenticeship

Практический маршрут для развития в AI systems engineering и техническом AI leadership.

## Начать здесь

**[Актуальный roadmap: курсы, порядок, ссылки и награды](WORK_INTEGRATED_ROADMAP.md)**

1. NVIDIA CUDA Python.
2. Git → GitLab CI/CD → экзамен, когда готов.
3. Linux Foundation DevOps/SRE.
4. NVIDIA RAG.

Один курс за раз, 3–5 часов в неделю. После завершения — сертификат или badge на стену и одна запись о том, что стало понятнее. Полные условия, цены, prerequisites и запасные пути находятся в roadmap.
